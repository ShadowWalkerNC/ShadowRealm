# Browser & Web Automation Engine

## Description
Uses Chrome DevTools MCP and Playwright/Puppeteer browser tools to automate web navigation, form submission, screenshot inspection, and web app testing.

## Instructions
1. **Navigate Target Web App**: Inspect DOM elements, handle ARIA accessibility labels, and track network responses.
2. **Execute Interactive Flows**: Fill out text fields, click action buttons, and trigger webhooks.
3. **Capture Visual Verification**: Take DOM screenshots and verify visual layout integrity.
