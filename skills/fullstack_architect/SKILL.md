# Full Stack Web Application Architect

## Description
Guidelines for architecting, building, and auditing full-stack web applications using FastAPI, HTML5, Vanilla CSS glassmorphism UI, and REST API endpoints.

## Instructions
1. **Design Tokens & System**: Use dark mode glassmorphism, responsive grid layouts, and clean typography.
2. **API Endpoint Layer**: Build modular REST API routers under `routes/` with Pydantic payload validation.
3. **Frontend Integration**: Implement clean ES modules without heavy external framework bloat.
4. **Security & Input Validation**: Sanitize inputs, enforce path confinement, and handle edge-case exceptions fail-closed.
