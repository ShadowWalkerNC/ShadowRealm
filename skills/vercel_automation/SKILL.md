# Vercel Deployment & Cloud Automation Skill

## Description
Guidelines and CLI workflows for deploying full-stack web applications, static sites, and serverless functions to Vercel via the Vercel CLI (`vercel`).

## Instructions
1. **Deploy Project**: Run `vercel --prod` or `vercel` for preview deployments.
2. **Inspect Deployments**: Use `vercel ls` to list active deployments and `vercel logs` to inspect runtime logs.
3. **Configure Environment Variables**: Manage project environment variables via `vercel env`.
