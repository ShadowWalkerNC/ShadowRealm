# 4-Stage Repository Audit Skill

## Description
Executes automated 4-stage repo analysis: Plan & Spec Audit, Build & Test Check, Code Integrity Analysis, and Synthetic User Persona Simulation.

## Instructions
1. Run `RepoAuditEngine` against target repository.
2. Evaluate test output and static syntax pass.
3. Generate structured markdown audit reports (`docs/AUDIT_REPORT.md`).
