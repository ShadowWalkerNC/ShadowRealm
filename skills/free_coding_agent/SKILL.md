# Free AI Coding Suite & Autonomous Agent Execution

## Description
Full autonomous AI software engineering workflow using free coding models (OpenCode Zen/Go, Ollama `qwen2.5-coder`, `deepseek-r1`, Groq). Performs multi-file refactoring, static analysis, unit test generation, and automated 4-stage repo audits.

## Instructions
1. **Analyze Requirements**: Parse target task and identify affected modules across local repositories.
2. **Execute Multi-File Refactoring**: Inspect function signatures, preserve API contracts, and update dependency files.
3. **Execute Automated Verification**: Run static syntax compilation and pytest suites.
4. **Run 4-Stage Repo Audit**: Execute `RepoAuditEngine` to verify plan spec, build health, code integrity, and user persona simulations.
